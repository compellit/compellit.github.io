The Galician Automatic Poetry Analysis System (GALAPAGOS) is online at **[https://prf2.org/galapagos/](https://prf2.org/galapagos/)**. GALAPAGOS is under developement at the COMPEL project and performs the following tasks for poetry in Galician:

- Metrical scansion
- Enjambment detection
- Rhyme detection
- Stanza classification

It includes rhyme and stanza modules developed by [Anxo Alonso](https://citius.gal/team/anxo-alonso-perez/) and integration of all modules into the web UI by Xabier Suárez.
