This page lists the web interfaces developed in the project and its presence on open platforms. Software, datasets, papers and other productions are listed on the [publications]({% link _pages/publications.md %}) page.

## Web-based interfaces

For data annotation and exploration.

- [GALAPAGOS · Galician Automatic Poetry Analysis System](https://prf2.org/galapagos/): User interface for our poetry annotation tools.
- [GALAPA*VIS* · Galician Automatic Poetry Analysis System _visual_](https://galapavis.app.citius.gal): Visualization of annotated poetry corpora in Galician and Spanish.

## Online platform presence

- GitHub · [compellit](https://github.com/compellit): code and data
- Hugging Face · [compellit](https://huggingface.co/compellit): models
- Zenodo · [compel](https://zenodo.org/communities/compel/): releases, preprints, other productions
